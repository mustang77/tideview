Cara membuat perubahan tampil di toko

  1. Atur harga/margin di sini. Perubahan otomatis tersimpan di browser ini.
  2. Klik Export catalog.json — file akan terunduh.
  3. Upload catalog.json ke folder paramall di Webuzo (sebelah index.html).
  4. Buka paramall.h2olaundry.com → harga & produk ikut ter-update. ✅
