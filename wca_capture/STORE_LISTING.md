## Privacy practices tab — exact answers

- **Single purpose**: "Captures and annotates screenshots and records the
  screen, only when the user explicitly requests it."
- **Permission justifications**:
  - `activeTab`: "Grants one-time access to capture the page the user
    explicitly chose to screenshot by clicking the extension."
  - `scripting`: "Injects the area-selection overlay into the current page
    when the user chooses 'Capture selected area'."
  - `storage`: "Passes the captured image from the background worker to the
    editor page, locally."
- **Data usage**: This item does not collect or use user data.
- **Remote code**: No.
